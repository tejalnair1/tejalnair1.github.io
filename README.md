# Tejal Nair — Academic Website

A responsive, static academic website built for GitHub Pages.

## Publish with GitHub Pages

1. Create a GitHub repository. For a personal site, name it
   `<your-github-username>.github.io`.
2. Add the files in this folder to the repository and push them to the `main` branch.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main`
   and `/(root)`, and save.
5. GitHub Pages will publish the site at `https://<your-github-username>.github.io/`.

The site is plain HTML and CSS, so it does not require a build step or external
packages. Update `index.html` and the files in `assets/` to change the site content,
portrait, or CV.
